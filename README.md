# 🎯 Guess the Number Game

A fun and simple web-based game where you try to guess the number randomly generated by the computer between 1 and 100.

## 💡 How to Play

- Enter a number between 1 and 100.
- Click the **Submit** button.
- Get hints whether your guess is too high or too low.
- Keep guessing until you get the correct number!
